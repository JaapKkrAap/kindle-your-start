# Background Assets

Place background images in this directory. The naming convention is:

`{location}-{timeOfDay}-{mood}.jpg`

Examples:

- `indoor-day-neutral.jpg`
- `urban-night-tense.jpg`
- `nature-day-romantic.jpg`
- `fantasy-night-mysterious.jpg`

Supported values:

- **Location**: indoor, outdoor, urban, nature, fantasy
- **Time**: day, night
- **Mood**: neutral, romantic, tense, mysterious, peaceful

If an image is missing, the application will fall back to a default gradient.
